
# 3-Month Plan for Learning Machine Learning & Mathematics (Parallel with Real-World Projects)

## Month 1: Foundations & Basic Models

### Week 1-2: Linear Algebra + Simple Regression
- **Math Focus:**
  - **Topic:** Vectors, matrices, and basic operations.
  - **Free Resource:**
    - [Khan Academy – Linear Algebra](https://www.khanacademy.org/math/linear-algebra)
    - [3Blue1Brown – Essence of Linear Algebra (YouTube)](https://www.youtube.com/playlist?list=PLZHQObOWTQDMsr9K-rj53DwVRMYO3t5Yr)
  - **Goal:** Learn about matrix operations, dot products, and eigenvectors.

- **ML Application Focus:**
  - **Topic:** Linear regression, cost functions, and gradient descent.
  - **Free Resource:**
    - [Coursera – Machine Learning by Andrew Ng](https://www.coursera.org/learn/machine-learning) (Free to audit)
    - [Scikit Learn - Linear Regression](https://scikit-learn.org/stable/modules/linear_model.html#ordinary-least-squares)
  - **Project:** Build a **House Price Prediction** model using Kaggle dataset.
    - **Dataset:** [Kaggle – House Prices](https://www.kaggle.com/c/house-prices-advanced-regression-techniques)

---

### Week 3-4: Calculus + Logistic Regression
- **Math Focus:**
  - **Topic:** Derivatives, gradients, and optimization.
  - **Free Resource:**
    - [Khan Academy – Differential Calculus](https://www.khanacademy.org/math/calculus-1)
    - [3Blue1Brown – Calculus Basics (YouTube)](https://www.youtube.com/watch?v=WUvTyaaNkzM)
  - **Goal:** Learn how derivatives are used in gradient descent for optimization.

- **ML Application Focus:**
  - **Topic:** Logistic regression for binary classification.
  - **Free Resource:**
    - [Scikit Learn – Logistic Regression](https://scikit-learn.org/stable/modules/linear_model.html#logistic-regression)
    - [Logistic Regression – Towards Data Science](https://towardsdatascience.com/a-complete-guide-to-logistic-regression-babb31f7a1f8)
  - **Project:** Build a **Spam Detection** system (SMS Spam classification).
    - **Dataset:** [UCI SMS Spam Collection](https://www.kaggle.com/datasets/uciml/sms-spam-collection-dataset)

---

## Month 2: Intermediate ML Concepts

### Week 5-6: Probability + Naive Bayes / Decision Trees
- **Math Focus:**
  - **Topic:** Probability distributions, Bayes' theorem, conditional probability.
  - **Free Resource:**
    - [Khan Academy – Probability and Statistics](https://www.khanacademy.org/math/statistics-probability)
    - [Harvard Stat110: Probability](https://projects.iq.harvard.edu/stat110)
  - **Goal:** Understand probability distributions (Gaussian, Bernoulli), Bayes' theorem, and conditional probability.

- **ML Application Focus:**
  - **Topic:** Naive Bayes classifier and Decision Trees.
  - **Free Resource:**
    - [Scikit Learn – Naive Bayes](https://scikit-learn.org/stable/modules/naive_bayes.html)
    - [Scikit Learn – Decision Trees](https://scikit-learn.org/stable/modules/tree.html)
  - **Project:** Build an **Iris Flower Classification** model and **Titanic Survival Prediction** model.
    - **Datasets:** [UCI Iris](https://archive.ics.uci.edu/ml/datasets/iris), [Titanic – Kaggle](https://www.kaggle.com/c/titanic)

---

### Week 7-8: Vectors & Geometry + Image Classification
- **Math Focus:**
  - **Topic:** High-dimensional vectors, distance metrics (Euclidean distance, cosine similarity).
  - **Free Resource:**
    - [Khan Academy – Vectors and Geometry](https://www.khanacademy.org/math/geometry)
    - [3Blue1Brown – Geometry (YouTube)](https://www.youtube.com/watch?v=EOVMlLthKpQ)
  - **Goal:** Understand how vectors and distance metrics are used in clustering and KNN.

- **ML Application Focus:**
  - **Topic:** KNN (K-Nearest Neighbors) and Transfer Learning for Image Classification.
  - **Free Resource:**
    - [Scikit Learn – KNN](https://scikit-learn.org/stable/modules/neighbors.html#nearest-neighbors-classification)
    - [TensorFlow – Transfer Learning for Image Classification](https://www.tensorflow.org/tutorials/images/transfer_learning)
  - **Project:** Build a **Dog vs Cat Image Classifier** using Transfer Learning.
    - **Dataset:** [Kaggle – Dogs vs Cats](https://www.kaggle.com/c/dogs-vs-cats)

---

## Month 3: Advanced Topics + Deployment

### Week 9-10: Multivariable Calculus + Neural Networks
- **Math Focus:**
  - **Topic:** Multivariable calculus, partial derivatives, backpropagation.
  - **Free Resource:**
    - [Khan Academy – Multivariable Calculus](https://www.khanacademy.org/math/multivariable-calculus)
    - [MIT 6.036: Introduction to Machine Learning – Neural Networks](https://ocw.mit.edu/courses/electrical-engineering-and-computer-science/6-036-introduction-to-machine-learning-fall-2020/)
  - **Goal:** Understand optimization techniques and backpropagation in neural networks.

- **ML Application Focus:**
  - **Topic:** Neural Networks and Deep Learning.
  - **Free Resource:**
    - [DeepLearning.AI – Neural Networks](https://www.coursera.org/learn/neural-networks-deep-learning) (Free to audit)
    - [Neural Networks Tutorial](https://www.youtube.com/watch?v=Ilg3gGew3H8)
  - **Project:** Build a **MNIST Digit Classifier** using a deep neural network.
    - **Dataset:** [MNIST](http://yann.lecun.com/exdb/mnist/)

---

### Week 11-12: Statistics + Model Evaluation & Tuning
- **Math Focus:**
  - **Topic:** Hypothesis testing, p-values, confidence intervals.
  - **Free Resource:**
    - [StatQuest – Hypothesis Testing (YouTube)](https://www.youtube.com/watch?v=3jv7Jxow3kI)
    - [Khan Academy – Advanced Statistics](https://www.khanacademy.org/math/statistics-probability)
  - **Goal:** Understand statistical inference and model evaluation metrics.

- **ML Application Focus:**
  - **Topic:** Model evaluation (confusion matrix, precision/recall, ROC curve), hyperparameter tuning.
  - **Free Resource:**
    - [Scikit Learn – Model Evaluation](https://scikit-learn.org/stable/modules/model_evaluation.html)
    - [Grid Search for Hyperparameter Tuning](https://scikit-learn.org/stable/modules/grid_search.html)
  - **Project:** Build a **Marketing Campaign Classifier** using hyperparameter tuning.
    - **Dataset:** [UCI Bank Marketing](https://archive.ics.uci.edu/ml/datasets/bank+marketing)

---

### Capstone Project (Final Week of Month 3):
- **Week 13:** Develop a **Real-World Application** of your choice (e.g., **Sentiment Analysis**, **Mental Health Text Classifier**, or **Product Recommendation**).
  - **Deployment:** Use **Streamlit** or **Flask** to deploy your project.
    - [Gradio for Building ML Web Apps](https://gradio.app/)
    - [Streamlit for ML Model Deployment](https://streamlit.io/)
    - [Flask for Deployment](https://realpython.com/python-web-app-with-flask/)
  - **Review:** Model evaluation, hyperparameter tuning, and deployment on platforms like **Heroku**.
    - [Heroku Deployment Tutorial](https://devcenter.heroku.com/articles/getting-started-with-python)

---

## Weekly Breakdown (Example):
- **Monday to Friday:**
  - **1 hour:** Focus on **Math theory** and exercises.
  - **1.5 hours:** **ML theory & Projects** – Build models, work on datasets.
  - **30 minutes:** **Review & hands-on** – Practice concepts, refine projects.

- **Saturday/Sunday:**
  - **2-3 hours:** Focus on **Projects** – Continue building, testing, or deploying.
  - **1 hour:** **Weekly Review** – Recap what you've learned, rework weak areas.
